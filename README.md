# 声明：
**本项目是Koreader阅读器的微信读书插件，基于finlater的weread.koplugin的魔改**

**禁止用于商业用途**

# 登录与认证

插件只支持微信扫码登录，不需要创建或维护配置文件。

扫码前需要先为账号开通微信读书 Skill：

1. 手机打开微信读书 App。
2. 进入 我 → 设置 → 微信读书 Skill。
3. 点击 获取 API Key，确认已经生成个人官方 API Key。
4. 在 KOReader 打开 工具 → 微信读书 → 微信扫码登录。
5. 使用微信扫码并在手机端确认；若手机显示四位验证码，请在 KOReader 中输入。

# 主要功能

微信读书app端与Koreader 微信插件的双端同步。

1. 下载远端阅读进度：将微信读书app的阅读进度下载Koreader本地并跳转到对应页面。
2. 同步当前书籍进度：将Koreader本地的阅读进度上报给腾讯，微信读书打开同一本书籍自动跳转到Koreader上传的页面。

# 便携功能

 增加快捷手势，在Koreader阅读器任意在读的书籍页面均可触发。

 手势：
 1. 下载远端阅读进度。
 2. 同步当前书籍进度。
 3. 微信书架。
 
# 更多功能

默认未开启**书籍图片**、**公众号文章图片**及**划线和想法**，需要开启的进入微信读书插件**设置-下载内容**下自行开启所需功能。
